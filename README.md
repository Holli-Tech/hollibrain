# hollibrain
how to build a Production Brain

The Production Brain project is aimed at providing a knowledge management system for studio and TV content creation.
The foundation of that work is Andrej Karpathy's work on the llm-wiki, that creates a "second brain" type of organisation for markdown files, with an agent keeping the sync of the links.

The different components of the project : 

-LLM-Wiki : Karpathy's skill 
-mdbook : a Rust web renderer of the markdown wiki
-Movielabs Ontology For Media Creation that articulates the 
-FastMCP to make 
-htpasswd to manage users
